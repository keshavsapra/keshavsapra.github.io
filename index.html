  1. 01

    Find the friction

    Every project here started as a moment of pain. A backup command to memorize, a note export nobody can read, a broken display switcher.

  2. 02

    Build the smallest fix

    No frameworks unless they earn their place. The tool does one job and quits, so it stays understandable years later.

  3. 03

    Ship it open source

    MIT or Apache 2.0, no accounts and no telemetry, so anyone on the same island of hardware can use it as is.
